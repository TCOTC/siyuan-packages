在顶栏和命令面板中提供常用开发辅助：重载窗口、打开插件相关目录、切换开发者工具。桌面端使用系统开发者工具，移动端使用 [vConsole](https://github.com/Tencent/vConsole)。

适用于全部前后端，在发布服务中禁用。

## 功能

- **重载窗口**：调用思源接口刷新界面，无需重启整个应用
- **打开插件目录**：在系统文件管理器中打开工作空间的 `data/plugins`
- **打开插件存储目录**：打开工作空间的 `data/storage/petal`（各插件的持久化数据）
- **切换开发者工具**
  - 桌面端 / 桌面端独立窗口：切换 Electron 开发者工具
  - 移动端 / 浏览器移动端：显示或隐藏 vConsole 绿色开关；首次使用会创建实例，主题跟随思源明暗模式

## 使用方式

**桌面端、桌面端独立窗口、浏览器桌面端**：点击顶栏上的开发者工具按钮，在菜单中选择对应操作。

**移动端、浏览器移动端**：右侧栏提供两个独立选项：重载窗口、切换开发者工具（vConsole）。

以上操作也都注册为命令，可在 **设置 → 快捷键** 中自行绑定。默认快捷键为空。

## 各端差异

| 能力             | 桌面端 / 独立窗口   | 浏览器桌面端 | 移动端 / 浏览器移动端 |
| ---------------- | ------------------- | ------------ | --------------------- |
| 重载窗口         | ✓                   | ✓            | ✓                     |
| 打开插件目录     | ✓                   | —            | —                     |
| 打开插件存储目录 | ✓                   | —            | —                     |
| 开发者工具       | 客户端内置 DevTools | —            | vConsole              |
