# 面包屑快捷全屏

在文档面包屑上添加全屏按钮，支持分别配置编辑器全屏和窗口全屏。

适用于桌面端、桌面端独立窗口、浏览器桌面端。

## 功能

- 面包屑按钮：点击后按当前设置切换全屏
- 编辑器全屏：当前文档铺满窗口，与思源原生编辑器全屏效果一致
- 窗口全屏：桌面端将应用窗口全屏；浏览器端使用页面全屏
- 图标跟随实时状态：用原生快捷键或系统全屏改过状态后，按钮仍显示正确的进入 / 退出图标
- 编辑器全屏和窗口全屏都禁用时，不显示面包屑按钮

## 设置

在插件设置中可分别打开或关闭：

- **编辑器全屏**：让当前文档编辑器铺满窗口
- **窗口全屏**：桌面端通过 Electron API 将应用窗口全屏；浏览器端使用页面全屏 API

默认两项都开启。

## 切换规则

只处理已开启的项，已关闭的项不会被改动。

- 已开启的项里只要有一个还不是全屏，点击后全部进入全屏
- 已开启的项都已是全屏，点击后全部退出

例如同时开了两项：编辑器已经全屏、窗口还没有，再点按钮会补上窗口全屏，而不会退出编辑器全屏。

## 快捷键

插件提供命令「切换当前编辑器全屏」，默认置空快捷键。可在 **设置 - 快捷键** 中自行绑定。按下后对当前活动编辑器执行与按钮相同的切换；焦点不在编辑器里时，会使用最近一次聚焦的文档。
