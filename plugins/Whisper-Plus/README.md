> **Recent update**: Fixed the theme appearance state not updating when switching SiYuan's appearance mode

1. Install this plugin in the marketplace and enable it
2. Use the <kbd>Enable Whisper theme</kbd> option in the plugin menu; if the theme is not installed, it will be installed automatically from the marketplace
3. Or manually install and enable the [Whisper theme](siyuan://bazaar/themes/Whisper/readme) in the marketplace

Plugin menu entries:

- Desktop: top bar button (flower icon)
- Mobile: "Whisper theme" entry in the more menu
