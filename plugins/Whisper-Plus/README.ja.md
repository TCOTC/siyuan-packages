# 囁き+

1. マーケットで本プラグインをインストールして有効にします
2. プラグインメニューの <kbd>囁きテーマを有効にする</kbd> オプションを使用します。テーマが未インストールの場合は、マーケットから自動的にインストールされます
3. または、マーケットで [囁きテーマ](siyuan://bazaar/themes/Whisper/readme) を手動でインストールして有効にします

プラグインメニューの入口：

- デスクトップ：トップバーのボタン（花のアイコン）
- モバイル：「囁きテーマ」はメニューにあります
