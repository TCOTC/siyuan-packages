# 临时编辑

在顶栏添加一个按钮，点击后打开「临时编辑」页签，使用 Protyle Lite 编辑器撰写内容。

## 特性

- 仅桌面端可用（自定义页签依赖桌面端布局）
- 顶栏按钮一键打开临时编辑页签，重复点击会切换到已打开的页签
- 编辑器使用 Protyle Lite，支持 Markdown 所见即所得输入、斜杠菜单、块引用等
- 内容不保存在任何地方，**关闭页签、关闭思源、刷新页面后无法找回**
- 支持一键复制 Markdown、清空内容

## 数据如何做到不落盘

- Protyle 以 `lite: true` 运行，编辑事务由前端 `LocalUndo` 记录，不会调用 `/api/transactions` 提交到内核
- 编辑器不绑定块 ID（`blockId: ""`），不会读取或写入任何文档
- 上传地址置空，粘贴图片等资源时会直接失败，不会写入 `data/assets`
- 内容仅存在于当前页面内存中，不会写入工作空间 `data/`，也不会写入浏览器本地存储
